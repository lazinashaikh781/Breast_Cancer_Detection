# Breast Cancer Detection Using Machine Learning

## Project Overview
This project uses machine learning classification algorithms to predict whether a breast tumor is benign or malignant using the Breast Cancer Wisconsin Diagnostic dataset.

## Objectives
- Analyze and clean the dataset.
- Explore features using data visualization.
- Train and compare multiple machine learning models.
- Evaluate models using accuracy, precision, recall, F1-score, and confusion matrices.
- Identify important features for prediction.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Joblib

## Machine Learning Models
- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest

## Project Workflow
1. Dataset loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Training and testing split
5. Model training and comparison
6. Evaluation and visualization
7. Model saving

## Dataset
Breast Cancer Wisconsin (Diagnostic) dataset, obtained from Kaggle.

Dataset source: https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data

## Results
Model performance metrics and graphs are available in the notebook. Actual scores depend on the trained models and evaluation setup.

## Disclaimer
This project is for educational purposes only and is not intended to provide medical diagnoses.
